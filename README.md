A 2D action RPG adventure game built with Godot Engine where you play as an immortal being capable of possessing different characters and creatures.

## 🎮 Game Overview

In Immortal Drift, you embark on an epic journey as an immortal entity with the unique ability to possess various characters and animals. Switch between different forms, each with their own abilities, to overcome challenges, defeat enemies, and explore the world.

## ✨ Features

### Character Classes
- **Default Player** - Balanced stats and abilities
- **Light Mage** - Harnesses the power of light magic
- **Fire Mage** - Wields destructive fire spells
- **Lightning Mage** - Commands electrical attacks
- **Shinobi** - Agile warrior with stealth abilities
- **Vampire** - Dark creature with unique powers

### Enemies & Bosses
- **Regular Enemies**: Slimes, Goblins, Lizards, Medusas, Dragons, Minotaurs
- **Bosses**: Evil Wizard, Gorgon
- **Wildlife**: Various animals that can be possessed

### NPCs
- Interactive characters including guards, mages, soldiers, and civilians
- Rich world with story elements and quests

### Core Mechanics
- **Possession System**: Take control of different creatures and characters
- **Combat System**: Real-time action combat with various attack types
- **Health & Regeneration**: Dynamic health system with regeneration
- **Death Mechanics**: Transform into a ghost upon death

## 🎮 Controls

- **Movement**: WASD or Arrow Keys
- **Attack**: A key
- **Possess**: P key (possess nearby creatures/characters)
- **Reset Position**: R key (return to starting position)

## 🚀 Getting Started

### Prerequisites
- [Godot Engine 4.3](https://godotengine.org/download) or later

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/Tasriad/Immortal-Drift.git
   ```
2. Open Godot Engine
3. Click "Import" and navigate to the project folder
4. Select the `project.godot` file
5. Click "Import & Edit"

### Running the Game
1. In Godot, press `F5` or click the play button
2. Select the main scene when prompted (`res://scenes/main_menu.tscn`)
3. Enjoy the game!
